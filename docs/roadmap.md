# Roadmap

| Phase | PRD | Status | Dependency |
|---|---|---|---|
| Establish inventory | PRD-001 | proposed | product router/component access |
| Build foundations | PRD-002 | proposed | approved inventory and security decisions |
| Secure actions/tools | PRD-003 | proposed | PRD-002 request context and policy |
| Migrate consumers | PRD-004 | proposed | stable v1 contracts and telemetry |

## Decision gates

1. API/security owners approve the product-specific profile and authorized targets.
2. Product teams approve contract source of truth and compatibility window.
3. Deployment/provider validation receives target-bound approval separately.
4. Legacy retirement receives measured consumer readiness and release approval.
